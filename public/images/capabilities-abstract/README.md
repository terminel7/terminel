# Capabilities abstract art

These images supply the scrolling image sequence on `/capabilities/` and `/home-2/`, plus the four sticky capability images on `/home-2/`.

Replace a file in place to update every use of that image without changing code. Keep the filename and use a high-quality `.webp` image at least 1200px on its longest edge. Portrait or landscape images both work because the site crops them with `object-fit: cover`.

- `01-strategy-glass.webp` - Strategy feature image and animation tile
- `02-creative-textile.webp` - Creative feature image and animation tile
- `03-brand-forms.webp` - Branding feature image and animation tile
- `04-development-systems.webp` - Development feature image and animation tile
- `05-prismatic-motion.webp` - Animation tile
- `06-optical-overlap.webp` - Animation tile
- `07-material-weave.webp` - Animation tile
- `08-growth-lens.webp` - Animation tile

The exact animation order lives in `src/lib/capability-art.ts`.
